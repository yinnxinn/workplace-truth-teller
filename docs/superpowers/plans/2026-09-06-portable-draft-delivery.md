# 通用草稿交付改进

用户已确定三层降级与跨运行平台配置目标，按现有授权直接实施。

维护源：当前配置 GitHub origin 的完整项目 `skill/`。其他本地副本只同步本次交付模块变更，保留独立内容生成改动。当前功能分支 `codex/portable-draft-delivery`。

## 范围

- 通用 JSON 配置：无账号凭据值、固定端口、浏览器 Profile 或操作系统依赖。
- Skill 指导宿主完成官方 API、授权浏览器、手动包三层交付。
- 离线计划器校验配置和能力快照，返回可执行下一步；不是独立 API 客户端或浏览器驱动。
- 模糊写入必须先回读；明确安全拒绝停止，不切换工具绕过。
- API 账号接入、真实创建草稿和公开发布不属于本次离线验证。
